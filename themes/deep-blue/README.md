# Deep Blue

Deep blue dark theme with the Kyoko violet accent. It starts from the built-in `dark` theme and overrides the surface, text and interaction colors. It was called Midnight until the built-in Midnight theme (refact0r's) took that name.

Apply it from Settings, Themes, Built In, or copy `theme.json` into your themes folder. See `docs/themes.md` for the token list.
